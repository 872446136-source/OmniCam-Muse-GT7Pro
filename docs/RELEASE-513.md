# 513 测试版：XPAN 成片与哈苏水印修复

日期：2026-11-16。验证设备：真我 GT7 Pro（RMX5010），相机 7.013.51、相册 17.10.41。

本次提交包含 512 的已交付基线及随后完成的 XPAN、水印修复。POP 色调仍未完成，513 不包含为排查色调而增加的预览增益、原生缓冲处理或临时诊断钩子。

## 修复与实拍结果

- **XPAN 保存成普通 4:3**：在现有水印处理链中实际裁切图像缓冲，按照 HAL 交付尺寸计算约 65:24 的居中区域。克隆每张照片的布局参数，让文字与边距按裁切后图像计算，处理结束后释放临时缓冲。开启 XPAN 水印的实拍输出为 1668×5084，图像内容为 1512×4096，标志和文字不再重叠。
- **关闭 XPAN 水印仍需裁切**：使用不写入用户设置的临时无文字样式，让裁切后的图像进入原有编码链。关闭水印的实拍为 1512×4096，没有可见水印或边框。
- **普通哈苏列表混入 XPAN、第三张卡过宽**：保留相册传入的模式参数，恢复普通样式与缩略图的对应关系；使用 XPAN 分区的实际资源 ID 和页面模式，仅在 XPAN 页面展示专用卡。已检查普通列表、选择样式和拍摄结果。
- **普通与 XPAN 的水印互相覆盖**：默认启用独立状态，在模式切换与冷启动时分别恢复样式、开关和备份。相册内置素材也可恢复，无须依赖已下载的样式目录。普通→XPAN→普通实拍验证：XPAN 保持水印关闭，输出 1512×4096；普通模式恢复 hassel_style_1 和开启状态，输出 3072×4608。
- **512 基线**：保留独立 POP 拍照会话、已传入预览参数的转发、两套调色配置与 LUT、哈苏内置资源读取及合并后的快门声适配。详情见 [RELEASE-512](RELEASE-512.md)。

## 验证范围与待修项目

上传源码经过独立快照构建及离线检查；包括滤镜目录、保存设置、大师色彩组合、真实 LUT 对照、XPAN 边界与偶数对齐、POP 资源和哈苏启动检查。实拍覆盖上述 XPAN、水印场景，尚未覆盖所有镜头、HDR、横竖屏与实况组合。

POP 的光感、去锐化、色温与自然饱和度已有用户确认生效；**色调预览仍需修复并与保存照片保持一致**。本地实验已定位到预览 LUT 与成片滤镜使用不同处理入口，但实验尚未通过成片验证，不作为已完成修复发布。

上游基线仍为 Muse 4.4.4 的 03f199ce6d94d206718f51cfbecd6466d9bc5347。2026-11-16 已核对，没有新增提交需要合入；本次上传是 GT7 Pro 适配修复。
