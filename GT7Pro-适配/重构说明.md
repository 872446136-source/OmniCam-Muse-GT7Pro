# 重构说明（Muse 4.1 GT7Pro）

这一版把"轻量版 / 完整版"两条分支合并成**一个包**，并换掉整套移植思路。下面说清楚改了什么、
为什么改、本机每个功能的真实状态。

产物：https://github.com/872446136-source/OmniCam-Muse-GT7Pro/releases/tag/full
分支：`test/full`

---

## 1. 上一版为什么黑屏

不是钩子写错了，是**替换了不该替换的东西**。上一版 `module/post-mount.sh` 把上游 X9 Ultra 的
`libAlgoInterface.so`、`libBasicTonePhoto.so` 覆盖到本机 `/odm/lib64/`，`post-fs-data.sh` 又覆盖了
`camera_unit_config`、`oplus_camera_config`、决策配置、ISP 调校 bin、gamma 表。

三个致命点：

| 点 | 事实 |
|---|---|
| SoC 不同 | X9 Ultra 是天玑 9500，GT7 Pro 是骁龙 8 Elite。`AlgoProcessData` 这类结构体布局不同，同名库不能互换 |
| 配置格式不同 | 本机 `oplus_camera_preview_decision_config.json`、`oplus_camera_aps_config`、`oplus_camera_algo_switch_config` **是加密的**（可打印率 0.36，无 JSON 字符串），X9 的是明文。把明文塞给本机等于喂垃圾 |
| 调校文件不同 | 本机是 `com.qti.tuned.sunny_imx906_main.bin` 这套高通调校，X9 是 `lighthouse*` |

所以相机进程在打开取景器之前就死了 —— 表现为"取景器全黑 + 进相机卡死"。

**这一版的做法：一个系统文件都不换。** 所有功能重建在本机自己的库和文件上。

## 2. 架构改动

### 2.1 删掉 Lite

`Profile.java` 整个删除，`installLiteCamera` / `installLiteGallery` 删除，`ModuleEntry` 只有一条路径。

### 2.2 能力探测（`common/Capabilities.java`）

运行时探测本机到底有什么，每个功能按结果决定装不装：

| 探测项 | 含义 |
|---|---|
| `dataLayer()` | 模块的数据层挂上没有（`/odm/etc/camera/meishe_lut` 与父目录不同设备 = 挂上了） |
| `lmt()` | 本机有没有 `/odm/etc/camera/basictone/lmt`（大师色彩 / GR 的宿主目录） |
| `retro()` | 有没有 `basictone/setting_Retro`（POP 必需） |
| `plainDecision()` | 决策配置是不是明文（首字节是 `{`）。X9 是，本机不是 |
| `tuningJson()` | 有没有 `conf_tuning_params.json`（天玑平台才有） |
| `hasMode(name)` | 本机 `camera_unit_config` 的 `mode_type_list` 里有没有这个模式 |

### 2.3 装配注册表（`common/Install.java`）

每个功能一行状态，三种结果：

- `on` —— 装上了
- `off: 原因` —— 本机缺东西，跳过（不影响其它功能）
- `failed: 异常` —— 装的时候抛了，只关掉自己

关键改进：**缺一个输入不再让整个相机功能全灭**。上一版只要 `/odm` 没挂上，`UnmountedGuard` 就把
所有钩子全关；现在纯 Java 功能照常，只有依赖数据的那几个自己跳过。

### 2.4 诊断页能看到结果

设置 → 诊断页新增「功能装配」一行，直接列出 `N 项已启用，M 项未启用：功能（原因）`。
这是这一版最重要的一点：**不用猜，装上就知道什么能用**。

## 3. 本机功能状态

实测依据来自 `dump/omnicam_dump`（本机 `/odm` 与 `/odm/lib64` 的完整导出）。

### 3.1 可用

| 功能 | 依赖 | 说明 |
|---|---|---|
| 滤镜目录 | 数据层 | `meishe_lut` 42 个 LUT 叠加到本机 107 个之上 |
| X10 滤镜 + 调色板 | 数据层 | `x10_basictone`：`lmt/` 9 个 + `palette/HDR|SDR/` 18 个 + 4 个 palette ini |
| 哈苏超清滤镜 | 数据层 | 高像素模式的滤镜条目 |
| 大师滤镜补全 | 数据层 | 额外 LUT、霓虹辉光、Portra 光晕 |
| GR 移植 | lmt + 原生 | 模式开关、预览 LMT、焦距、比例、快门声 |
| GR 水印 5 套 | 数据层 | 相机端 + 相册端，5 个 JSON + 20 个 webp |
| 大师色彩 | lmt + 原生 | 自带 C++ LMT 引擎，只往本机 lmt 目录送表，不换库 |
| 水印系列解锁 | 纯 Java | |
| 批量水印 | 纯 Java | 多选菜单里加 / 撤销 |
| 地址跳转 | 纯 Java | 照片详情里的地址打开地图 |
| 快门声 | 纯 Java | 静音 / 振动模式下仍响 |
| 快启键 | 纯 Java | 快启键打开指定模式 |
| 模式状态分离 | 纯 Java | 每个模式独立的闪光灯 / 实况状态 |
| 4K60 滤镜 | 纯 Java | 普通视频 4K / 60fps 下滤镜可用 |
| 机型伪装 | 纯 Java | |
| 视频水印保护 | 纯 Java | |
| 相机日志镜像 | 纯 Java | |
| 相册调色板 | 数据层 | 加载 `jiege_ipu` 里的 unit SDK jar |
| 专业视频 ISZ | 本机文件 | 只改本机 `CameraHWConfiguration.config` 第 25–40 行，命中数不是 16 就整段跳过 |

### 3.2 部分可用

| 功能 | 原因 |
|---|---|
| 大师 LUT 槽 / 大师对比度 | 上游挂 `BasicTone::MergeLutTet_resize`，本机 `libBasicTonePhoto.so` **没有这个符号**（只有 `load3DLut`）。走 LUT 加载路径的部分生效，走 merge 的部分不生效 |
| 物理柔光 | 上游挂 `MsRenderHDRTexture` + `MsRenderHardwareBuffer`，本机 `libmsnativefilter.so` **只有前者**。预览路径生效，成片路径不生效 |

### 3.3 本机自动跳过（代码保留）

这些不是删掉，是**本机缺前提，装上会坏事**，所以自动跳过；换成 X9 或其它满足条件的机器会自动打开。

| 功能 | 缺什么 | 能不能补 |
|---|---|---|
| 25MP 解锁 | 决策配置加密，改不了 | 需要平台的解密 key，本机没有 |
| 200MP 人脸门禁 | 同上，且本机主摄是 50MP | 硬件上不存在 |
| POP 复古相机 | 本机 `basictone` 没有 `setting_Retro`，`mode_type_list` 没有 `retro_mode` | 需要 POP 模式的决策树 |
| XPAN（实况 / 取景净化 / 水印隔离） | `mode_type_list` 没有 `xpan_mode`（只有 vendor tag） | 需要模式 + 决策树 + UI 资源 |
| 移轴拍摄 | `mode_type_list` 没有 `tilt_shift_mode`（只有 vendor tag） | 同上 |
| 自然色彩 | 没有 `conf_tuning_params.json`，也没有 `libOPAlgoCamHDRTransformCamera.so` | 天玑专属 |

> 关于"把模式加进 `mode_type_list`"：`camera_unit_config` 是明文，技术上可以改。但决策配置
> 是加密的，模式加进去也没有对应的决策树，大概率是空白界面或直接崩。这一版不做这种盲改。

## 4. 模块脚本改动

### `post-fs-data.sh`

- **不再** bind 任何 `.so`、任何 `config/` 下的文件、ISP bin、gamma、audio policy
- 只做两件事：叠加挂载 `meishe_lut`（本机 107 + 上游 42）、叠加挂载 `basictone`（本机 + x10 曲线 + `setting_Retro`）
- 机型守卫：`/odm/etc/camera/meishe_lut` 或 `basictone` 不存在就什么都不挂
- 专业视频 ISZ：从**本机**文件打补丁，行数对不上就跳过

### `service.sh`

- 只往 app 私有目录写数据：GR LMT profile、大师色彩数据、字体、GR 水印样式、调色板 jar
- 删掉：`pop_port` staging、`pld_watermark`、`apk_resources`、`unlock25mp`、`face200m`、移轴 DB 重置
- HDR 能力列表只保留本机真实存在的模式（去掉 `xpan` / `retroCamera`）
- 所有等待都加了上限，不会卡住开机

### `uninstall.sh`

同步本版：多清两个开关文件，其余照旧。卸载无残留。

## 5. 新增开关

```bash
# 只关原生层（Java 功能照常），用来二分定位原生钩子的问题
adb shell su -c "touch /data/adb/omnicam_native_off"

# 整体关掉
adb shell su -c "touch /data/adb/omnicam_off"

# 恢复
adb shell su -c "rm -f /data/adb/omnicam_off /data/adb/omnicam_native_off"
```

改完重启。

## 7. 出问题怎么回退

按顺序试，每步重启：

1. `touch /data/adb/omnicam_native_off` —— 只关原生层，判断是不是原生钩子的问题
2. `touch /data/adb/omnicam_off` —— 整体关掉，相机应回到完全原样
3. KernelSU 里停用模块 —— 连数据层挂载一起撤掉
4. 卸载模块 —— 走 `uninstall.sh`，清干净

## 8. 已知取舍

- **GR 的饱和度 / 对比度 / 清晰度**：上游由原生层写进 LMT 参数，本版原生层在，但这些参数走的是
  `MergeLutTet_resize` 路径，本机没这个符号，所以只有 LUT 生效，数值不生效。
- **快门独立音量档位**：需要挂上游的 `audio_policy_volumes.xml`，本版不换系统音频配置，所以只有
  「静音模式下仍响」生效，独立音量不生效。
- **包体 227 MB**：`master_color/looks` 占 253 MB（未压缩），是大师色彩的成片查找表，属于功能本体。
  不需要大师色彩可以删掉 `payload/master_color` 重新打包，包会降到 ~30 MB。
