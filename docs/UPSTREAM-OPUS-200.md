# Opus 2.0.0 更新日志与 GT7 Pro 适配记录

核对日期：2026-11-17（北京时间）。最初按用户要求仅在本地编译安装包；随后按用户新要求将 513 保存到 `release/513` 正式分支、514 上传到 `test/514` 测试分支。未运行 GitHub 构建，未更新线上 Release。

用户提供的参考包：`OmniCam-Opus-Release-2.0.0-KSU.zip`。包内设置应用为 `local.jiege.camera`，版本 2.0.0，面向 Find X9 Ultra。已保存的公开上游源码仍是 Muse 4.4.4，提交 `03f199ce6d94d206718f51cfbecd6466d9bc5347`；因此不能把该提交当成 Opus 2.0.0 源码基线。

## 上游更新日志

以下为用户提供的 Opus 2.0.0 更新内容，属于上游发布说明，不代表每项已经在 GT7 Pro 可用：

1. UI 全面焕新，使用 COUI 框架，带来凝光视效，更贴近 OPPO 原生设计。
2. 优化功能分区、文案和排版。
3. 首页卡片点击五次触发彩蛋，展示经典胶片、相机、OPPO 机型介绍；默认每天一张，大师、GR、XPAN 快门数可按比例兑换额外抽卡次数。
4. 引入全新胶片模拟引擎，提供胶片与暗房参数组合。
5. 增加胶片属性介绍、比较色卡，以及暗房参数简介和「更多信息」。
6. 胶片引擎支持光晕和颗粒等空间效果；光源补偿控制光晕强度，画幅控制颗粒尺度。
7. 增加「偏移量」曝光补偿，可分别调节色彩引擎亮暗；上游建议胶片正值、HNCS −0.3 至 −0.7 EV。
8. 优化大师色彩引擎性能，加快 LUT 烘焙并减小模块体积。
9. 大师色彩引擎切换时不再杀死相机，支持前台小窗对比。
10. 增加哈苏官方 PHOCUS 全套水印，支持拍照直出和后期编辑。
11. 增加小米徕卡水印，支持拍照直出和后期编辑。
12. 解除相册视频编辑导出实况的长度限制。
13. 解除默认视频美颜的规格限制。
14. 修复大地探索家水印反色失效。

## 514 本地适配状态

| 项目 | 本地实现 | 验证边界 |
| --- | --- | --- |
| 大师色彩实时切换 | 大师色彩整数设置不再主动关闭相机，沿用当前预览 LUT 更新路径，读取周期 200 ms | 需要相机前台小窗确认预览与成片一致 |
| 分引擎曝光 | 各引擎分别保存偏移量、对齐点与模式；旧设置迁移为「沿用旧设置」，保留原来的偏移量加对齐行为 | 可单独切换「偏移量」或「曝光对齐」；离线测试覆盖独立键、计算与迁移默认值 |
| 视频美颜规格 | 接入普通视频美颜阻挡、菜单可用及分辨率/帧率冲突入口；默认关闭 | 新入口需通过本机 APK 符号回放；开启后的实际规格需真机测试 |
| 相册实况导出 | 接入视频编辑导出时长配置，默认关闭；本机直接导出所选起止区间，无上游额外时长函数；较新相册的任务内时长和文案入口为可选 | 和参考包实际代码一致，上限为 24 小时，不能称作数学上的无限时长；普通菜单导出保持原路径 |
| XPAN、普通哈苏水印 | 保留已上传的 513 修复 | 本轮没有整包替换原机配置或算法库 |
| POP 色调 | 保留本地未提交实验 | 数学测试和编译通过不等于五个滑杆全部修复；原生捕获路径含特定固件结构偏移，仍需真机验证 |
| COUI、分区与凝光 | 未移植 | 新版应用界面与本项目 Compose 设置页结构不同，不能把成品 APK 当源码覆盖 |
| 首页抽卡及快门兑换 | 未移植 | 尚未接入计数、额度持久化与 UI |
| 新胶片核心、暗房、色卡、光晕和颗粒 | 未移植 | 新包使用 `fotufilm.bin` 等独立引擎数据，格式及接口不同于现有 Spektrafilm；不能只换文件名或新增无效控件 |
| 烘焙性能和包体优化 | 未移植 | 当前仍编译原有大师色彩核心，不能宣称采用了 Opus 新核心 |
| PHOCUS、徕卡水印 | 素材已准备，功能未接入 | 素材清单与 SHA-256 在 `work/opus-2.0.0/watermark-resources/manifest.json`；选择入口与渲染逻辑未接通，素材不加入安装包 |
| 大地探索家反色 | 参考素材已准备，修复未接入 | 反色还取决于渲染参数，只有图片不构成完整修复 |

新版安装包可以用于核对可见 Java 接口和素材，但不能提供完整、可重新编译的新原生核心。要完成新版核心的等价移植，需要作者的对应实现或完整的接口与数据格式说明；也可以另行实现并验证兼容引擎。本轮产物明确标记为 514 本地测试版，仍以原有 Muse 核心为基础。
