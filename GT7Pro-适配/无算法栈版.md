## 这一版做了什么

完整版（`full-port-test`）在 GT7 Pro 上取景器全黑、进相机卡死。黑屏的直接原因在算法层，所以这一版
把 **Find X9 Ultra 独有的算法栈整层拿掉**，只留数据层和纯 Java 钩子。

### 拿掉的（算法栈）

| 完整版做的事 | 本版 |
|---|---|
| `libjiege_native.so` 在相机进程里 patch `libAlgoInterface` / `libBasicTonePhoto`（按 X9 Ultra 的 so 写死 25021 决策族偏移） | 不打包：APK 里没有 `.so`，`assets/native_init` 已删，`app/src/main/cpp` 整目录删除 |
| bind 上游 `libBasicTonePhotoX9.so` / `X10.so` / `libCombineLut.so` | 不打包 `module/system/`，`post-mount.sh` 删除 |
| bind 上游 `camera_unit_config` / `oplus_camera_config` / 决策配置 / ISP 调校 bin / gamma 表 | 全部不挂 |
| staging `master_color` 引擎数据、`unlock25mp`、`face200m`、`pld_watermark`、`apk_resources`、`jiege_ipu` | 全部不 staging |

对应功能：POP 复古相机、25MP 解锁、哈苏超清 200MP 去人脸门禁、大师色彩 / HNCS / Lumix / 胶片 look、
自然色彩、物理柔光、大师 LUT 槽 / 对比度 / 颗粒、大师滤镜补全、移轴、相册调色板、XPAN、无缝模糊保护。
代码还在，由 `Profile.NATIVE_STACK = false` 关掉；设置界面里对应的开关也一起隐藏了。

### 保留的（数据层 + Java）

| 分类 | 功能 |
|---|---|
| 滤镜 | 滤镜目录注入（普通 / 大师两套分开管）、X10 滤镜、哈苏超清里的滤镜与调色板条目、4K60 下普通滤镜不降级 |
| GR | GR 模式、预览 LMT、焦距、比例、快门声、GR 水印 5 套样式（相机 + 相册） |
| 水印 | 水印系列解锁、批量加水印 / 撤销、视频水印保护、机型伪装（EXIF + JPEG） |
| 相册 | 照片详情地址跳转地图 |
| 相机 | 快门声（静音/振动下也响）、快启键指定模式、闪光灯与实况按模式分离、日志镜像 |
| 配置 | 专业视频 ISZ（2x 主摄 / 6x 长焦 / O-Log2）：只改本机 `CameraHWConfiguration.config` 第 25–40 行，命中行数不是 16 就整段跳过 |

只 bind 两棵**数据树**，都是往本机现有目录上叠加，不替换任何文件：

```
/odm/etc/camera/meishe_lut    本机原有 + 42 个 LUT
/odm/etc/camera/basictone     本机原有 + X10 basictone 35 组 + GR setting_Retro 2 个
```

## 装完怎么确认

```bash
# 1. 数据层挂上了没有（应该 2 行 dir bind ok）
adb shell su -c "cat /data/adb/modules/ricoh_pop_x9u/bind.log"

# 2. 没有替换任何库（下面这条应该是空的）
adb shell su -c "ls /data/adb/modules/ricoh_pop_x9u/system" 2>&1

# 3. 版本
adb shell dumpsys package local.jiege.camera | grep versionName
# 期望 Muse 4.0 GT7Pro nostack
```

设置应用 → 主页 → 注入状态：三项都应该是绿的；「KSU 模块」那行现在显示的是
**滤镜 / GR 数据已挂载**（本版不换库，所以检测的是 LUT 目录）。

## 预期与取舍

1. **GR 出片的成像参数不完整。** GR 预览 LUT 由 Java 层接管，取景和成片都会套 GR 的 LMT；但饱和度 /
   对比度 / 清晰度这些是 `gr_basictone.cpp` 写进 APS 请求的，本版没有原生层，这几项不生效。
2. **快门音量自定只生效一半。** 上游的 `audio_policy_volumes.xml` 是按 X9 Ultra 改的，没 bind（怕影响
   整机音量曲线），所以「静音/振动下仍响快门声」正常，「独立快门音量档位」按本机默认走。
3. **GR 水印字体**从相册已下载的 `files/watermark_master/materia` 复制；相册没下载过字体时退回默认字体。
4. 这一版**不会**再出现全黑取景器：没有任何 `.so` 被替换，也没有任何上游相机配置被挂上。

## 卸载残留

`uninstall.sh` 已按本版同步更新，卸载时清理：`files/jiege`、`files/ricoh_gr`、
`files/mode_limit_watermark`、相册 `files/ricoh_gr_styles`、`mode_data.db`、写入的 7 个相机设置键、
相册 GR 开关，最后卸载 `local.jiege.camera`。日志在 `/data/local/tmp/omnicam-uninstall.log`。
本版不再往 `files/pop_port`、`files/odm`、`files/jiege/mastercolor`、`files/jiege/unlock25mp`、
`files/jiege/face200m`、相册 `files/jiege_ipu` 写东西，所以这几处本来就不会有残留。

## 如果还有问题

```bash
adb shell su -c "sh /sdcard/诊断.sh"   # 或把仓库里的 诊断.sh push 进去
```

把生成的 `/sdcard/omnicam-diag-*.txt` 发回来。同时可以先做一步二分：`touch /data/adb/omnicam_nostack_off`
重启，确认关掉模块后相机是正常的——这一步能区分是模块的问题还是别的问题。
